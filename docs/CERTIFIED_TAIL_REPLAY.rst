Final-turn certificate: complete-cohort computational extension
==============================================================

This extension reuses all512 sources from the completed, independently exported
prospective incumbent comparison. It generates no new source matches. It cannot
be frozen or launched before that comparison finishes and passes its export.
The original four-contrast strength decision remains fixed and separate.

The cohort contains both parents, both published opponents and both seats on128
deal streams. Missing roots and support refusals remain in the denominator.
Every previously evaluated root is included, without outcome or cost selection.
The original history-compatible weighted worlds are reused with bound hashes;
hidden actual state is not used to construct a policy.

Both the contingent controller and root-only control use the final-opponent-turn
certificate. The controller receives separate2M-transition/500k-node fixed and
optimized phases, retaining the original skip conditions and no budget transfer.
The root-only control receives4M transitions/1M nodes. Both keep depth32 and
frontier4096. Fresh empty actor caches per arm; original arm order is retained.
All other selection, actor, belief and execution rules are unchanged.

The original artifacts supply the computational controls. This is not an
alternating fresh-run latency benchmark. Compare physical transitions, physical
terminal completions, represented simulations, symbolic certificate mass,
completed parent references, capped phases, adoptions and conditional gains.
Operational timings are reported separately and cannot isolate speedup.
More complete phases may increase total work even when individual expansions
are cheaper, because the original controller skipped optimization when its
parent reference could not finish.

For every root action completed by both implementations in the same phase,
require identical exact values and full learner-policy maps. Partial upper
bounds may tighten. Newly completed policies have no old complete comparator.
Every adoption independently replays the unchanged parent and selected policy
with Python rules; the verifier expands the omitted opponent moves and counts
its additional actor calls. Policies are saved before actual-tail execution.
The three actual tails are replayed from the same saved root, with unchanged
parent/fallback outcomes required. These are conditional executions, not fresh
source matches or independent confirmation.

Four workers process32 chunks of16 sources, with a20GiB free-space guard.
Maximum additional native planning allowance is4,096,000,000 transitions;
oracle and actual-tail replay work are separate. No source extension, cap
increase, result-based subset, model promotion or reserved101M use is authorized
by this protocol. Complete-only audit verifies all bindings, policies and
actual traces before producing descriptive reused-cohort means. It produces
no new strength gate or confidence intervals.

Commands, after the original export passes::

  python -m scripts.certified_tail_replay --freeze
  python -m scripts.certified_tail_replay --launch
  python -m scripts.certified_tail_replay --audit

The certificate's rule proof and synthetic capability evidence are in
OPPONENT_LAST_TURN_CERTIFICATE.rst. Neither this runner nor the certificate
changes production play or the original prospective study.
