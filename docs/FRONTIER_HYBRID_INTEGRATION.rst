Integration of the frontier fallback
===================================

The complete eight-case frontier screen recovered positive conditional gains in
four previously refused roots. Integrate that mechanism only when the existing
symbolic controller returns parent_unvalued. Run its original fixed phase first.
If that phase produces a parent value, retain its original continuation,
optimization schedule, tie handling and executable selection exactly. Otherwise,
spend the skipped second-phase allowance on the frozen frontier-patch solver.

Each phase retains its two-million-transition ceiling. The second phase shares
its allowance across the prefix and every local comparison. No allowance moves
between phases. Unlike the development screen, integration executes the old
phase again; its work is new physical work rather than an imported historical
count. The total remains at most four million transitions per selected root.

Before a fresh strength study, reexecute all eight fixed refusal fixtures and
compare the complete original phase and patch with their audited saved results.
Each local world array, weight, model, binding, complete proposal, reference
interval, selected program and work counter must agree. Reusing the independently
verified values of identical programs is reported as reused evidence, with no
new value-oracle work claimed. Reconstruct root support anew and replay actual
parent/hybrid suffixes; patched suffixes must match the preceding screen.

Also select the first old strict_exact_gain and no_strict_gain source for each
parent, in the original closed cohort's order. These four preservation controls
must retain the complete old fixed/optimized phases and original selection,
without running the fallback. Select and bind all controls before execution.
All twelve cases remain; two bounded workers use fresh processes per case.

This is an integration and preservation check, not a fresh population study.
Source generation adds no independent matches or chance draws. The closed
cohort's denominator, outcomes and failed practical-gain test remain unchanged.
Human play, initial dealer and the deployed canonical actor remain unchanged.
