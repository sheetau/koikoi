======================================

251, 322, 738). No new source is drawn and no fixture is replaced. The prior
root-interval screen is closed before freezing this protocol.

Each fixture receives one million physical transitions for full-belief
contingent proposal search and one million for the unchanged-parent reference,
without borrowing. Proposal live-node and reference expanded-task caps are
250,000 each; they count different operations and must remain separate.

and the reference pending-row cap is 65,536. Two bounded worker processes run.

planner, compiled to a complete legal-public-override program with parent
default. A partial proposal produces no candidate. The reference uses exact
intervals for the unchanged parent. Adoption requires candidate lower value
strictly above parent upper value. The method and certificate-transfer proof
are in ``PROPOSAL_INTERVAL_TAIL.rst`` and ``INTERVAL_TAIL.rst``.

reconstructs the complete posterior and compares every world/mass with the
previous saved support. Save the candidate, reference interval and selection
before oracle and actual execution. Independently replay every completed
compiled candidate through all Python transitions and stock branches. Also
replay the parent for every adoption or newly exact parent. Native policy
caches and symbolic outcome shortcuts are excluded from these oracles.

Actual parent/controller tails are independently replayed. The parent must
match the recorded source suffix; a fallback must match the parent. Separate
proposal, reference, represented, support-audit, oracle and actual/replay work.
