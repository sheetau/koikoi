Interpreting the koi-temperature comparison
==========================================

The learning comparison fixes the intervention and outcome criterion. This
separate diagnostic asks how the final policies differ on common public inputs.
It cannot select a checkpoint, temperature, learning budget or evaluation deal.
Run only after all four training endpoints finish; inspect only initial and
final models. Intermediate checkpoints are not evaluated.

Use two explicitly different populations. First, take every unforced public
observation from the 25 old validation source matches used by the score-only
calibration (nonnegative source ID modulo four equals three). These matches did
not set the temperature. They were generated by an old random policy and do
not estimate the learning or deployment state distribution. Second, pool all
128 saved environment states at each of the four final training endpoints.
These 512 snapshots are actual visited states, sampled at one update boundary;
they do not reconstruct complete rollouts or provide an unbiased visitation
estimate. Retain each source arm in the report and exclude terminal/forced
rows from entropy summaries while reporting their counts.

Evaluate original WP, retained A/B and all four final learners on both common
populations. Generate only the existing public/own-hand actor features and
public endgame mask. Use singleton CPU float32 execution with two threads and
the ordinary inference parameter settings. Keep network requires_grad flags
unchanged and disable gradient recording. Store scores, source indices, masks
and phases so scalar findings can be checked without another neural pass.
No environment step, rollout, outcome label or optimization is required.

For each population and decision phase, report the raw top-two score gap,
greedy-action changes against original WP, stop-to-continue and reverse changes,
and entropy/greedy probability at both temperature0.05 and the model's declared
training temperature. On common inputs, the former separates learned score
changes from the immediate probability transformation; the latter describes
the declared sampling distribution of the final model on those inputs. These
are descriptive diagnostics, not confidence intervals or a mediated causal
effect. The frozen 49,152-match comparison supplies the strength evidence.

Relation to prior work
----------------------

Haarnoja et al., *Soft Actor-Critic Algorithms and Applications* (2019 version,
arXiv:1812.05905), Section5, adjust temperature to meet an entropy target over
visited states. Entropy targets and automatic temperature adjustment therefore
precede this study. Here the temperature is fixed before PPO training using an
old corpus, and only one decision head changes. This does not implement SAC or
inherit its policy-improvement results.
https://arxiv.org/html/1812.05905

Cesa-Bianchi et al., *Boltzmann Exploration Done Right*, NeurIPS2017, analyze
temperature schedules in stochastic bandits and propose an alternative with
arm-dependent learning rates. Their results already show that Boltzmann
exploration requires careful parameter choices. They do not establish a
guarantee for a nonlinear, partially observed self-play PPO learner.
https://papers.nips.cc/paper/2017/hash/b299ad862b6f12cb57679f0538eca514-Abstract.html

The potential contribution is a reproducible account of a phase-specific
adaptation bottleneck in released Koi-Koi value networks, if the controlled
outcomes support it. A different temperature or a diagnostic alone is not a
new general learning method. Keep this distinction when integrating a completed
positive or negative result into the paper; do not add a success claim now.
